# Referencias visuales de interfaz
Capturas de un panel de administración moderno, usadas **solo como referencia de estilo** (distribución, jerarquía, tarjetas, tablas con etiquetas de estado). No copiar código, textos, logotipos ni fotos de la plantilla.

| Archivo | Se usa para |
|---|---|
| 01_inicio_tablero | Pantalla de inicio de cada rol: indicadores arriba, actividad reciente, tarjetas |
| 02_perfil_para_historia_clinica | Cabecera del paciente + secciones en tarjetas + línea de tiempo de atenciones |
| 03_calendario_NO_USAR | **Fuera de alcance** (no hay agenda de citas). Solo se incluye para que se vea qué NO hacer |
| 04_login_dos_columnas | Login: panel izquierdo con título y una frase, tarjeta de acceso a la derecha |
| 05_directorio_para_lista_y_cola | Lista de pacientes, cola de admitidos, lista de usuarios: filtros por estado, etiquetas, paginación |
| 06_reportes_con_graficos | Reportes del administrador del hospital (barras y anillo) |

Regla: cada pantalla nueva se compara contra la referencia que le corresponde antes de darse por terminada.
